### RD 判定
符号化時の 2 つの判定（決定の MV と MV 候補、決定とスキップモード）を、予測の SATD ではなく、各候補の予測の輝度の残差を最大の変換サイズで DCT して量子化したコスト（量子化ステップ単位の二乗誤差 + 係数ビット）+ モードビット × 0.05 で比べる。
- 重み 0.025 / 0.05 / 0.1: anime A −12.7 / −11.7 / −5.0%、anime C +1.3 / −1.7 / −2.1%。
- 色差を含めても anime A の結果はほぼ同じ（±0.7% のサイズ、±0.04 dB）で 0.87 倍の速さなので、輝度だけ。
- 速度の落ち込みは当初 40% あった。原因の半分は実験用の環境変数を候補ごとに `getenv` で読んでいたことで、残りは DCT と量子化（ほぼ半々）。TCQ をやめても速くならなかった。

GUI のプリセットは TCQ で同じ qindex の画質が約 2.5 dB 上がったため、TCQ 前と同じ PSNR になる qindex に変えた（高画質 45→60、標準 150→165、小容量 180→195。クリップと anime A の両方で同じ値になった。7f3eefa）。

### NEARMV の不利（バイアス）
符号化時に、決定の MV と MV 候補（NEARMV）を予測の SATD で比べている。SATD は「決定の MV が残差まで見て選ばれている」ことを反映しないので、候補を選びすぎていた。候補に何ビット足すかで:

| バイアス | anime A | クリップ（通常） | anime C | anime D |
|---|---|---|---|---|
| 2 | −2.8% | | −0.4% | −0.7% |
| 4 | −4.8% | −0.7% | +0.3% | −1.3% |
| 6 | −6.7% | −0.6% | +2.6% | −1.7% |
| 8 | −4.3% | | | |

4 と 6 は平均が同じで、6 は anime C で大きく負けるので 4 にした。

### スキップモード
B フレームで、ブロックを「前後の参照の平均（MV は候補リストから）」として 1 フラグで符号化する。残差は別に付けられる。決定の予測の SATD + 8 ビットと、スキップ候補の SATD + 番号のビットを比べて選ぶ。8 ビットの値は 4 / 8 / 12 を比べて決めた（anime A −8.1 / −8.9 / −6.5%、anime C +0.4 / −5.5 / −6.7%、anime D +0.4 / +0.8 / +1.4%）。

実装中に、以前からあった不具合を直した: NEARMV 判定の予測が、前のフレームの同じ位置の補間フィルタを使っていた。このため B フレームの並列符号化と逐次符号化で出力が変わっていた。

## 次に何を作るか: AVM でツールを1つずつ切った結果

AVM（`--cpu-used=4`、ループ復元も探索される設定）で、CelV2 にないツールを 1 つずつ切った BD-rate（プラス = 切ると悪化 = そのツールの価値）。クリップ a / d、10 フレーム、qindex 60/100/140/180。

| ツール | a | d |
|---|---|---|
| スキップモード | +0.25% | **+2.70%** |
| 拡張分割 | +0.45% | +1.03% |
| 前方スキップ符号化（FSC） | +1.22% | +0.43% |
| マスク合成 | +0.17% | +0.06% |

- 1 つのツールの価値はどれも 1〜3% 以下。いちばん大きかったスキップモードは実装した。
- 同じ条件で CelV2 は AVM より +18.3%（クリップ a、10 フレーム）。2026-10-25 の除去実験と合わせると、この差の大半はツールではなく判定の質。

### 実素材での AV1 比較（CelV2 = 9ce88eb、同じ画質で CelV2 が何 % 多く使うか）
| 素材 | NVENC AV1 p7 | SVT-AV1 preset 6 |

- VGA クリップでの差（NVENC +19%、SVT +62%）と同じ傾向。NVENC にはアニメで近いが、SVT-AV1 との差はまだ大きい。
- SVT-AV1 は 32 枚単位の階層 GOP、時間方向の重要度による qindex 調整（TPL）、グローバル / ワープ動き、ブロックごとの CDEF などを使う。
- 弱いところ: フェード（明るさの変化。AV2 には BAWP がある）、高解像度のなめらかな絵（AV2 は 128x128 / 256x256 のスーパーブロックを持つが CelV2 は 64x64）、実写。
- 注意: anime B の最初の 4 秒は平らなタイトル画面で、PSNR が飽和して BD-rate が当てにならない（ある変更で +48% と出たが、本編では −4%）。
