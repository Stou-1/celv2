# `--grain`：ノイズを除いて符号化し、デコーダーでグレインを足し戻す（2026-11-04）

## 結論

- `--grain 25` で、同じ qindex のバイト数が実写 3 本で q110 −14〜−28%、q150 −6〜−12%、q190 −1.4〜+0.3%。
- 時間は 1 つの qindex で 0.9〜1.4 倍（ほとんど 1.0〜1.2 倍）。ノイズ除去は最大 8 フレームを同時に処理する。
- PSNR（グレインを足す前の再構成と元の映像）は下がる。ノイズを除いた分の差で、設計どおり。良し悪しは見比べで決める。
- アニメ（AIR、Dragon Maid）にかけても −5〜−20% だが、PSNR が 0.5〜2.6 dB 下がる。AVM のノイズ除去は、ノイズがあるかどうかに関係なく `N / 10` の強さで効くので、きれいなアニメの線や塗りも少しぼける。既定はオフ。ノイズやフィルムグレインのある素材向け。
- AVM でデコードした映像は、グレインを除けば `--recon` と一致する（8 / 10 ビット、B フレームと隠しフレームの表示を含む。test_cli `cli_grain`）。

## 作り（docs/superpowers/specs/2026-11-03-film-grain-design.md）

- AV2 では、グレインの型（倍率の折れ線、AR 係数など）をフレームヘッダーに書かない。別の OBU（`OBU_FILM_GRAIN_MODEL`）でデコーダーに預け、フレームヘッダーには「型の番号と乱数の種」だけを書く。型の番号は 0 だけを使い、キーフレームの後と、型が変わってから 16 フレーム以上たったときに送り直す。
- 型の OBU は TU の最初のフレーム OBU より前に置く（AVM はフレームの後ろの型 OBU を受け付けない）。隠しフレームを前に抱えた TU でも同じ。
- 隠しフレームを後で表示する SEF も、そのフレームの種を書く（フレームバッファーに持たせた値から）。
- ノイズ除去（Wiener、32×32、ノイズの強さは固定）はフレームごとに独立なので並列。型の推定だけ表示順。

## 残り

- 見比べ（2026-11-05、利用者の判断）：吉村と crowd_run の q150 で、`--grain 25` のほうがグレインなしより良い。
- 強さの見比べ用に、q150 の「元 / 10 / 25 / 40」を並べた動画を作った（今の版。吉村 373 / 341 / 317 KB、crowd_run 4.42 / 4.22 / 3.98 MB、なしは 386 KB、4.48 MB）。動画は celv2-bench/view-grain。
- 強さの見比べ（2026-11-05、利用者の判断）：25。GUI の「詳細設定」の「フィルター」に「フィルムグレイン」を足した（既定 0、目安 25）。
- `--tune film` の既定を `--grain 25` にした（2026-11-05、利用者の判断）。`--target-vmaf` のときは除く（VMAF はグレインを足す前の映像で採点するので、ノイズを除いた分を符号化し直すおそれがある）。時間は静かな CPU で計る（ledger）。
