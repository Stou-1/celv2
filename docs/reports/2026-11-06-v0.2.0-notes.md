# CelV2 v0.2.0 リリースノート

## 圧縮と速度

v0.1.0 と比べて、同じ画質（PSNR-Y）でサイズが平均 10.66% 小さくなりました。一方で、符号化の時間は 1.4〜1.7 倍かかります。

| 素材 | BD-rate（120 フレーム 1080p、q100-190） |
|---|---|
| Dragon Maid | -20.85% |
| Angel Beats | -20.80% |
| AIR | -11.46% |
| AM | -10.80% |
| chika | -9.50% |
| park_joy | -4.53% |
| crowd_run | -3.70% |
| 吉村 | -3.63% |

アニメは `--tune animation`、実写は tune なしで測りました。

| 素材（600 フレーム 1080p、q130、空いた CPU） | v0.1.0 | v0.2.0 | 時間 |
|---|---|---|---|
| AM | 15.24 fps | 10.13 fps | 1.50 倍 |
| AIR | 16.14 fps | 9.47 fps | 1.70 倍 |
| Dragon Maid | 11.65 fps | 8.18 fps | 1.42 倍 |

`--tune film` はフィルムグレインの処理が加わるので、さらに時間がかかります（吉村 120 フレームで 1.57 倍）。

## 新しいこと

- Vulkan が既定の GPU になりました。RTX 5090 と Arc Pro B50 で動きます。
- `--screen`（既定 `auto`）：スクリーン映像と網点の絵で、パレットと IntraBC をフレームごとに使います。普通の映像はこれまでどおりです。門が開く素材（Flash など）は 1.12〜1.18 倍遅くなります。`--screen 0` で切れます。
- `--rd-zero`：残差を RD で 0 にします。`--tune animation` で有効です。実写は細部が減るので既定ではオフです。
- `--grain`：フィルムグレインの合成。`--tune film` は 25 が既定です。GUI の詳細設定にもあります。
- `--target-vmaf`：画質指定。`--target-size`：サイズ指定。GUI にもあります。
- CfL を RD で選ぶようになりました（`--cfl-rd`）。実写でも既定で有効です。
- `--psy-rd`、`--psy-trellis`、`--warp`：既定はオフです。

## 直したこと

- `--target-vmaf` で、長い動画が途中で止まる問題と、4K の短いシーンで落ちる問題を直しました。
- 大きなフレームで worker が複数のとき、Vulkan の VRAM が足りなくなる問題を直しました。

## 確かめていないこと

- `--screen auto` の 600 フレームの確認で、Angel Beats はソースがなく未実行です。
- 複数 worker の VRAM の修正は、8K の実機では動かしていません。
