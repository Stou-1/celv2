# キーフレームの符号化：64x64 のイントラブロックと RD によるモード選択（2026-11-03）

## 結論

- 2026-11-03 の Flash の比較（2026-11-03-flash-cirno.md）で、1 フレームだけでも CelV2 は同じ道具の avmenc（cpu-used 6）より +17〜+62% 大きかった。その原因を、ビット内訳とブロックの分布で調べた。
- 原因は 3 つ。(1) イントラブロックが 32x32 まで（avmenc は面積の 25〜61% を 64x64 以上で符号化している）。(2) 輝度モードを SATD だけで選んでいる（Flash では DC が面積の 46%、avmenc は 10%）。(3) MRL（参照ラインの選択）はモードを決めたあとに 1 つのモードでしか試していない（avmenc は Flash の面積の 32%、CelV2 は 2%）。
- 2 つ直した。イントラフレームの RD パスで 64x64 / 64x32 / 32x64 のイントラブロックも選べるようにした（`--intra64`、既定で有効）。符号化側で、SATD の上位 12 個の輝度モードを変換と量子化のコストで選び直し、MRL も同時に選ぶようにした。
- 120 フレームの 1080p 8 本（全体 MSE の PSNR-Y、`--refs 7`）で平均 −1.32%。悪化した素材はない。時間は 1.01〜1.15 倍。
- 1 フレームの avmenc との差は Flash で +44〜58% から約 +30%、AIR で +47% から約 +20% に縮んだ。

## 1 フレームでの調整（q100〜190、変更前との BD-rate、Flash 20 秒 / 100 秒 / AIR / AM / Dragon Maid）

- 64x64 のイントラブロック: コストそのまま +1.9 / −0.9 / −12.0 / +0.1 / −9.4%、1.1 倍 +1.3 / −1.3 / −12.3 / −1.2 / −9.3%、1.25 倍 +1.1 / −1.2 / −9.7 / −1.4 / −9.3%、24 ビット足す +1.5 / −1.5 / −10.4 / −0.0 / −8.9%。1.1 倍にした（`kIntra64Ratio`）。
- RD によるモード選択: 上位 4 個・ビットの重み 0.2 で −9.3 / −10.5 / −3.0 / −3.7 / −3.9%。そこから 2 個 / 8 個で平均 +1.8 / −0.5%、重み 0.1 / 0.3 で −2.2 / +3.0%、0.05 で −3.0%、0.05 で 8 個 / 12 個 / 全部（19 個）で −4.2 / −4.6 / −4.4%。12 個、重みは inter のモード比較と同じ 0.05（`kRdBitWeight`）にした。

## 残り（次の候補）

- 128x128 / 128x64 のブロック: avmenc は AIR の面積の 17% で使っている。CelV2 の判定は 64x64 単位。
- 色差のモード選択: avmenc は CfL を AIR の面積の 95%、Flash で 69% に使う。CelV2 はそれぞれ 36%、0%。CfL の評価は原画の輝度で予測した SATD を 1.2 倍している。
- 輝度の変換の選び方: avmenc のイントラはほぼ変換分割なしで、CelV2 は面積の 17〜21% を分割している。
