# CelV2 GUI アプリ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 動画ファイルをドロップしてプリセットを選ぶだけで、ffmpeg → celv2enc → av2_mux / MP4Box で AV2 の MP4（または IVF と音声ファイル）に変換できる WinForms アプリ（.NET Framework 4.8）を作り、zip で配れる形にする。

**Architecture:** 画面のない `CelV2.Settings`（設定・プリセット・入力の情報・コマンドラインの組み立て）と `CelV2.Runner`（ツールの検索・ffprobe・ffmpeg と celv2enc の起動とバイト列の中継・進み具合・中止）の上に、WinForms の `CelV2.Ui` と起動用の `CelV2Gui.exe` を置く。celv2enc には進み具合の行（`--progress`）を足す。

**Tech Stack:** C# 7.3、.NET Framework 4.8（WinForms、`System.Runtime.Serialization.Json`）、Visual Studio 付属の `csc.exe`（NuGet も .NET SDK も使わない）、既存の C++ / CTest。

**Spec:** `docs/superpowers/specs/2026-10-26-celv2-gui-design.md`

## Global Constraints

- .NET Framework 4.8 向け。この PC は 4.8.1 だが、4.8 にない API は使わない。`App.config` に `<supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8" />`。
- ビルドは `csc.exe`（`C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\Roslyn\csc.exe`）を `-langversion:7.3` で使い、参照は `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\` の DLL。NuGet のパッケージ、.NET SDK、外部のテストフレームワークは使わない。JSON は `DataContractJsonSerializer`。
- 組み込みプリセット: 「高画質」qindex 120、「標準」150（既定）、「小さめ」180。タイルの「自動」: 幅 1280 以上で `--tile-columns 1`、それ未満で付けない。
- 保存先: プリセット `%APPDATA%\celv2gui\presets\*.json`、設定 `%APPDATA%\celv2gui\settings.json`。
- 出力の既定は MP4（`av2_mux` で AV2 の映像だけの MP4 → MP4Box で音声を足す）。MP4 に入れる音声は AAC ならそのまま、それ以外は AAC 192 kbps に変換し、映像の長さ（フレーム数 ÷ fps）で切る。`av2_mux` は `--fps <rate>/<scale>`（IVF ヘッダの値）を必ず渡す。`av2_mux` か MP4Box が見つからなければ「別ファイル」に切り替えて知らせる。
- 「別ファイル」の音声: 最初の音声トラックを `-vn -c:a copy` で取り出す。AAC → `.m4a`、MP3 → `.mp3`、Opus → `.opus`、AC-3 → `.ac3`、FLAC → `.flac`、それ以外は AAC 192 kbps の `.m4a`。音声がなければ作らない。
- 道具の場所: ffmpeg / ffprobe / MP4Box は「設定で指定した場所 → exe と同じフォルダ → PATH」。`av2_mux.exe` と `celv2enc.exe` は exe と同じフォルダ（同梱）。別の作業のフォルダのファイルは変更しない（参照とコピーのみ）。この PC の道具: `av2_mux.exe` / `av2_demux.exe` / `avmdec.exe` は `<AVM のビルド>\bin\`、MP4Box は `%USERPROFILE%\gpac-26.07\mp4box.exe`。テストは環境変数 `AVM_BIN`（avmdec / av2_mux / av2_demux のフォルダ）と `MP4BOX_DIR` で受け取り、どちらかがなければその MP4 のテストを `SKIP（理由）` と表示して飛ばす（失敗にはしない）。
- ビット深度は 8 のみ。8 以外を指定したコマンドラインの組み立ては `NotSupportedException`。HDR（伝達特性 `smpte2084` / `arib-std-b67`）は `zscale` と `tonemap` で SDR にし、ffmpeg にそれらがなければ失敗にする。
- 出力先に同名があれば上書きせず `名前 (2).ivf` のようにずらす。中止と失敗では作りかけのファイルを消す。
- コメントは英語、画面の文言と説明書は日本語。コミットはリポジトリの設定の作者（`-c user.name/user.email` を付けない）、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。
- C++ のビルドとテスト: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1` / `scripts\test.ps1`（今は 16 本）。

## Review Focus

1. 音声のない入力: 失敗にせず、映像だけを作り、音声ファイルを作らない → Task 4 の `runner_video_only_input`。
2. 空白と日本語を含むパス（入力・出力・ツールの場所）: 引用符が正しく、ffmpeg と celv2enc が受け取れる → Task 3 の `quotes_paths_with_spaces_and_japanese` と Task 4 の `runner_japanese_paths`。
3. 動画として読めない入力（テキストファイルなど）: 理由を返して失敗にし、作りかけのファイルを残さない → Task 4 の `runner_reports_unreadable_input`。
4. ffprobe がフレーム数を返さない入力: 長さ × フレームレートで推定し、進み具合が止まらない → Task 3 の `probe_estimates_missing_frame_count`。
5. 出力先に同名のファイルが既にある: 上書きしない → Task 3 の `namer_avoids_existing_files` と Task 4 の `runner_does_not_overwrite`。

    public int Width, Height; public int FpsNum, FpsDen; public bool VariableFrameRate, Interlaced;
    public int BitDepth;                   // 8, 10, 12

    public static string ColrFor(InputInfo i, OutputFormat f);

  `VideoFilterFor` の順序: インターレースなら `bwdif=mode=send_frame`、可変フレームレートなら `fps=<FpsNum>/<FpsDen>`（`avg_frame_rate` を使う）、HDR なら `zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv`、最後に `format=<PixelFormatFor>`（8 ビットより深い入力か HDR のとき）。`DecodeArgs` は `-hide_banner -nostdin -loglevel error -i <input> -map 0:v:0 [-vf <chain>] -pix_fmt <PixelFormatFor> -f yuv4mpegpipe -`。`EncodeArgs` は `-i - -o <ivf> --qindex <q> [--tile-columns <n>] [--device gpu|cpu] [--keyint <k>] [--threads <t>] --progress`（`Auto` と 0 は付けない）。

  ```csharp
  public sealed class ToolPaths { public string Ffmpeg, Ffprobe, CelV2enc, Av2Mux, Mp4Box; }
  public static class ToolLocator {
    // ffmpeg/ffprobe: configured ffmpeg folder -> exe folder -> PATH. MP4Box: configured MP4Box folder
    // -> exe folder -> PATH. celv2enc/av2_mux: toolsFolder (the exe folder in the app, build\ and AVM_BIN in tests).
    // Members are null when not found.
    public static ToolPaths Find(string configuredFfmpegFolder, string configuredMp4BoxFolder, string toolsFolder,
                                 string av2MuxFolder);
  }
  public static class IvfToObu {
    // Strips the IVF file header (its length is the u16 at offset 6) and each 12-byte frame header
    // (u32 size + u64 pts); returns the header's rate and scale.
    public static void Convert(string ivf, string obu, out int rate, out int scale);
  }
  public sealed class Mp4Mux : IMuxStep {                  // av2_mux, then MP4Box -add when audio exists
    public Mp4Mux(ToolPaths tools, string colrOrNull, string outputMp4);
  }
  public static class Prober {
    public static InputInfo Probe(ToolPaths t, string input);           // throws with ffprobe's message
    public static bool HasFilters(ToolPaths t, params string[] names);  // runs `ffmpeg -hide_banner -filters`
    public static bool ParseHasFilters(string filtersOutput, params string[] names); // the parsing part
  }
  public interface IMuxStep {
    // Called after video and audio are written; returns the final output files.
    IReadOnlyList<string> Finish(string videoIvf, string audioOrNull);
  }
  public sealed class SeparateFilesMux : IMuxStep { }      // returns both files unchanged
  public sealed class JobProgress { public long Frame, Total; public double Fps; public TimeSpan Remaining; }
  public sealed class JobResult { public bool Ok, Cancelled; public string Error; public IReadOnlyList<string> Outputs; public string EngineLine; }
  public sealed class EncodeJob {
    public EncodeJob(ToolPaths tools, string input, InputInfo info, EncodeSettings s, string outputFolder, IMuxStep mux);
    public event Action<JobProgress> Progress;            // raised on a worker thread
    public event Action<string> EngineLine;               // "CelV2: decisions on ..." once
    public JobResult Run(CancellationToken cancel);       // blocking; video then audio then mux
  }
  ```
  `Run` は `Process` で ffmpeg（`DecodeArgs`、標準出力をリダイレクト）と celv2enc（`EncodeArgs`、標準入力と標準エラーをリダイレクト）を起動し、ffmpeg の標準出力の `BaseStream` を celv2enc の標準入力の `BaseStream` へ別スレッドでコピーする（コピーが終わったら標準入力を閉じる）。celv2enc の標準エラーを1行ずつ読み、`progress frame=N` で `Progress`、`CelV2: decisions on` で `EngineLine`、それ以外は最後の 20 行を保持してエラーの理由にする。中止は両方のプロセスを `Kill` して待ち、作りかけの出力を消す。`info.Hdr` のときは起動前に `Prober.HasFilters(tools, "zscale", "tonemap")` を確かめ、なければプロセスを起動せず `Ok == false`、`Error` に「HDR の変換に必要な ffmpeg の機能（zscale / tonemap）がありません」。映像の後に音声を取り出す（音声がなければ飛ばす）: `Container == Mp4` なら `Mp4AudioArgs`（長さ = FrameCount ÷ fps）、`Separate` なら `AudioArgs`。最後に `IMuxStep.Finish`。`Mp4` で `Av2Mux` か `Mp4Box` が null なら、`SeparateFilesMux` にして `JobResult.Note` に「MP4 に必要な道具（av2_mux / MP4Box）が見つからないため、別ファイルで保存しました」（`JobResult` に `public string Note;` を足す）。`Mp4Mux.Finish` は IVF を一時の `.obu` に変え（`IvfToObu`）、`av2_mux`、音声があれば MP4Box を実行し、成功したら IVF・`.obu`・音声を消して MP4 だけを返す。どちらかが失敗したら作りかけの MP4 と中間ファイルを消し、ツールのエラー出力の最後の数行を理由にして例外を投げる（`Run` はそれを `Ok == false` にする）。出力名は `OutputNamer.Stem`。
