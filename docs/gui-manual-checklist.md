# GUI 手動確認表

対象: `gui\bin\CelV2Gui.exe`（`gui\build.ps1` でビルド。この PC では `celv2enc.exe` と `av2_mux.exe` が `gui\bin` にコピーされる）。
スクリーンショット: `docs/gui-mainform.png`（変換中の主画面）。

凡例:
- 確認済み: プログラムから画面を動かして確かめた。方法を書いた。
- 要手動確認: 人が実機で見る必要がある。

確認に使った素材: ffmpeg で作った合成映像（`testsrc2` 640x480 3 秒 + 440 Hz の音声、名前は空白と日本語を含む `短い clip.mp4`。`testsrc2` 1280x720 60 秒 + 音声の `long.mp4`）と、中身が動画でない `bad.txt`。

## 起動

| 項目 | 結果 | 方法 |
|---|---|---|
| `CelV2Gui.exe` が起動して落ちない | 確認済み | プロセスを起動し 5 秒後に生きていること、ウィンドウの題名が出ていることを確認し、`CloseMainWindow` で閉じた |
| ffmpeg が PATH にあれば設定画面は出ない | 確認済み | 上の起動で設定画面が出なかった |

## ドロップと入力の確認

| 項目 | 結果 | 方法 |
|---|---|---|
| ドロップ処理（`DragEnter` が受け付け、`DragDrop` で一覧に載る） | 確認済み | `FileDrop` を持つ `DataObject` を作り、ドロップのイベント処理を直接呼んだ。3 本を渡して 3 行になった |
| Explorer から実際にドラッグ & ドロップ | 要手動確認 | 動画を 1 本、複数本、フォルダを、ウィンドウ上部の領域・一覧の上・ウィンドウの余白のそれぞれにドロップする |
| 「ファイルを選ぶ」ボタン（ファイル選択画面） | 要手動確認 | 複数選択ができること |
| 解像度・fps・長さ・音声が一覧に出る | 確認済み | `短い clip.mp4` が `640x480 / 30 / 0:03 / aac`、`long.mp4` が `1280x720 / 30 / 1:00 / aac` |
| 読めないファイル（動画でない `notes.txt`）は注意欄に短い理由（「読み込めません: Invalid data found when processing input」。パスは含まない）が出て「失敗」になり、変換では飛ばされる | 確認済み | 自動テスト `failure_reason_is_short` と画面。変換開始後も「失敗」のまま、他のファイルは変換された。全文は行のダブルクリック（要手動確認） |
| 注意欄の文言（10 / 12 ビット → 8 ビット、HDR → SDR、可変 fps → 固定、インターレース解除） | 確認済み | 自動テスト `notes_for_inputs` が、それぞれの `InputInfo` から注意欄の文字を組み立てる関数を直接調べる。実際の素材でのドロップは要手動確認 |
| 空白と日本語を含むパスの入力と出力 | 確認済み | `短い clip.mp4` が `短い clip (2).mp4` に変換された |

| 完了の通知音 | 要手動確認 | |
