CelV2 - 動画を AV2 に変換するアプリ

CelV2 は、動画を AV2 形式（MP4）に変換する Windows アプリです。符号化の判定を GPU（Vulkan に対応した GPU）で行います。
出力は AVM v1.0.0 の復号器で正しく復号できます。実験的なソフトで、AV2 に対応した再生ソフトはまだ少ないです。

■ 必要なもの

- Windows 10 / 11 の 64 ビット
- ffmpeg（ffmpeg.exe と ffprobe.exe）。このアプリには入っていません（下の「ffmpeg の入手」）。
- 速く変換するには Vulkan に対応した単体 GPU（GeForce RTX、Intel Arc など）。GPU がなくても CPU で変換できますが、とても遅くなります。
- 音声つきの MP4 を作るには MP4Box（GPAC）。任意です。なくても変換はでき、映像（.ivf）と音声を別ファイルで保存します。
- .NET Framework 4.8（Windows 10 の 2019 年 5 月の更新以降と Windows 11 には最初から入っています）。VC++ ランタイムは同じフォルダの DLL を使うので、インストールは不要です。

■ 使い方

1. zip をどこかのフォルダ（例: デスクトップや D:\CelV2）に展開します。Program Files の中は避けてください。
2. CelV2Gui.exe を起動します。
3. ffmpeg が見つからないと「ツール設定」が開きます。ffmpeg.exe と ffprobe.exe が入ったフォルダを選びます（あとから「ツール設定...」でも変えられます）。
4. 変換したい動画を画面にドロップするか、「ファイルを選ぶ」で選びます。複数入れると、上から順に1本ずつ変換します。
5. 「画質」を選びます（高画質 / 標準 / 小容量。迷ったら「標準」）。
   「内容」で動画の種類に合わせた設定を選べます（なし / アニメ / 実写 / 静止画多め。x264 の --tune と同じ考え方）:
   アニメは静止の多い場面でキーフレームを細かくし長い GOP を使います（アニメ 6 本で 0.1〜13.5% 小さく）。
   さらに時間方向の動きベクトル予測と、キーフレームのノイズを前後のフレームで均す処理を使います（同じ画質で AIR OP 240 フレームが 4.1%、アニメ混在 600 フレームが 4.3% 小さく、ほかは -1.0〜+0.6%）。
   実写は落ち着いた実写向けです（動きや粒子の多い実写ではわずかに大きくなります）。
   実写では、ノイズを除いて符号化し、再生のときにグレインとして足します（「フィルムグレイン」、自動で 25）。
   静止画多めはスライドやノベルゲームの映像向けで、動きの多い動画には向きません。
   「とても遅いが最高画質」をオンにすると、速さを無視して画質と圧縮率を優先します（--preset max）。
   ミニ GOP の長さとデブロックの強さを、実際に符号化して比べて選びます。FHD で 2〜3 倍以上時間がかかります。
   「詳細設定」では celv2enc のすべての設定をタブごとに変えられます:
   画質（qindex、元の動画より大きくしない・その上限）、フレーム構成（キーフレーム間隔、場面の切り替わり、B フレーム数、
   参照フレーム数、フレームの種類ごとの qindex 差）、フィルター（デブロック強度、CDEF、フィルムグレイン）、速度・処理（判定の場所、
   タイル横・縦、スレッド数、B フレームの並列処理、場面ごとの並列）、出力（形式、音声の kbps）。
   「判定の場所」には、このパソコンで使える GPU が名前で並びます（自動 = GPU（Vulkan）、
   なければ CPU）。どれを選んでも出力は同じで、速さだけが変わります。
   「場面ごとの並列」は、場面の切り替わりで区切って同時に変換します（自動 = CPU とメモリから決める）。出力は 1 つずつ変換したときと同じです。サイズ指定のときは、指定に近く収まるよう 1 つずつ変換します。場面の少ない動画は速くなりません。
   変換中に使うメモリは、搭載メモリの 8 割までに抑えます。足りないときは、並列の数、B フレームの並列処理の順に自動で減らします（注意に出ます）。
   「プリセットとして保存」で名前を付けて残せます。
6. 出力先を選びます（既定は入力と同じフォルダ）。
   出力するファイルの名前を変えるときは、一覧でファイルを選び、右の「出力名」に入力します（空欄なら入力と同じ名前）。
   同じ名前のファイルがすでにあるときは「 (2)」などを付けて、上書きはしません。
7. 「変換開始」を押します。進み具合・速さ・残り時間・判定の場所（使った GPU / CPU）が出ます。「中止」でいつでも止められます。
8. 終わったら「フォルダを開く」で出力を開きます。失敗した動画は理由が出て、次の動画に進みます。
   変換済みの動画は、もう一度ドロップすると一覧に加わります（画質や出力名を変えて、別のファイルとして出力できます）。

元の動画より大きくしない（既定でオン）:
- すでに圧縮された動画（MP4 など）を高画質で変換すると、元の圧縮のノイズまで細かく写し取るため、元よりずっと大きくなります
  （例: 30 MB の FHD 動画を高画質にすると 500 MB 以上）。
- そこで変換の前に、動画の 3 か所から短い見本を取り出して何通りか試し、映像のビットレートが元の動画を超えない範囲で
  いちばん細かい画質（qindex）を自動で選びます。調べるのに FHD で 15 秒ほどかかります。
- 調整したときは、一覧の「注意」に「qindex 60→145（元の動画より大きくならないよう調整）」のように出ます。
- 「詳細設定」の「圧縮済みの動画」で切れます。上限（元の動画の映像ビットレートの何 %、既定 90）も変えられます。

サイズ指定（MB）（「画質」の行、0 でオフ）:
- 出力するファイル全体（映像＋音声＋MP4 の分）を、指定した大きさ以下にします。アップロードの上限（10 MB など）に合わせるときに使います。
- 2 回変換します。1 回目でビット数を下調べし、2 回目で全体の画質（qindex）をなるべく一定に保ちながら指定に合わせます（指定の 97〜100% が目安）。時間は普段のおよそ 1.3〜1.5 倍です（超えてやり直したときは、その分長くなります。短い動画ほどやり直しが起きやすい）。
- 1 MB は 1,000,000 バイトとして数えます（MiB で上限が決まっているサービスでも超えません）。
- 超えたときは自動で予算を減らして 2 回目をやり直します（3 回まで）。それでも収まらないときや、音声だけで指定を超えるときは理由を出して失敗します。
- 音声の形式は設定のまま（コピー、AAC、HE-AACv2）です。小さくしたいときは「詳細設定」で HE-AACv2 と kbps を選んでください。
- オンのときは「元の動画より大きくしない」を使いません（サイズ指定の方が強い制限なので）。

出力形式:
- MP4（既定）: 映像（AV2）と音声を1つの .mp4 にします。MP4Box が必要です。
- 別ファイル: 映像を .ivf、音声を .m4a などで別々に保存します。MP4Box がなくても使えます。
  MP4 を選んでいて MP4Box（または av2_mux）が見つからないときは、「変換開始」を押したときに警告を出します。
  「はい」で「別ファイル」で変換し、「いいえ」で戻ります（「ツール設定...」で MP4Box.exe を選べます）。

MP4 にまとめる（再変換なし）:
- 「別ファイル」で保存した映像（.ivf）をドロップすると、同じ名前の音声（.m4a / .mp3 / .opus / .ac3 / .flac）と合わせて .mp4 にします。
  映像も音声も変換し直さないので、数秒で終わります。元の .ivf と音声はそのまま残ります。
- 「変換開始」で、ほかの動画と同じ一覧の順に処理します。出力先と出力名も同じように使えます（同じ名前があれば「 (2)」などを付けます）。
- 音声があるときは MP4Box が必要です（「ツール設定...」で選べます）。音声がなければ MP4Box なしでもまとめられます。

音声を HE-AACv2 にする（「詳細設定」の「出力」、既定でオフ）:
- オンにすると、音声をいつも HE-AACv2（ステレオ、既定 32 kbps、12〜96 kbps）に変換します。48 kbps くらいまでの低いビットレートで AAC より音がよくなります。
- fdkaac.exe（libfdk-aac を組み込んだもの）が必要です。このアプリには入っていません。「ツール設定...」で fdkaac.exe を選ぶか、
  CelV2Gui.exe と同じフォルダか ffmpeg のフォルダに置いてください。
  見つからないときは注意を出して、音声はいつもどおり（コピー、またはAAC）にします。サイズ指定で音声が大きすぎて失敗したときも、
  エラーに「fdkaac が見つからない」と出ます。

最後の変換のログ:
- 変換を始めるたびに %APPDATA%\celv2gui\last_encode.log を作り直し、使ったコマンド、各ツールのメッセージ、結果（成功・失敗の理由）を書きます。
  失敗の原因を調べるときに見てください（フレームごとの進み具合は書きません。8 MB で打ち切ります）。

映像は 10 ビットで符号化します（8 ビットの動画も 10 ビットにした方が小さく、きれいになります）。
10 ビット・12 ビットの動画は 10 ビットのまま、HDR（PQ / HLG）の動画は HDR のまま変換し、
色の情報とマスタリングディスプレイ・最大輝度（MaxCLL / MaxFALL）の情報も付けます。
可変フレームレート・インターレースの動画は、固定フレームレート・インターレース解除に自動で直してから変換します
（12 ビットの 10 ビット化とあわせて、一覧の「注意」に出ます）。

設定は %APPDATA%\celv2gui\settings.json に保存されます。

■ ffmpeg の入手

ffmpeg は広く使われている別のソフトで、このアプリには入っていません（ffmpeg の多くのビルドは GPL で、一緒に配ると条件が増えるため）。

1. https://ffmpeg.org/download.html から Windows 用のビルドを入手して展開します。
2. ffmpeg.exe と ffprobe.exe が入ったフォルダを、「ツール設定」で選びます。
   CelV2Gui.exe と同じフォルダに置くか、PATH の通った場所に置いても使えます。
   探す順: 設定で選んだフォルダ → CelV2Gui.exe のフォルダ → PATH。

MP4Box は https://gpac.io/downloads/gpac-nightly-builds/ から入手できます（GPAC は LGPL-2.1。同じく入っていません）。
MP4Box.exe が入ったフォルダを、「ツール設定」で選ぶか、CelV2Gui.exe と同じフォルダに置いてください（PATH の通った場所も探します。順は ffmpeg と同じ）。

■ Windows の警告（SmartScreen）

このアプリにはコード署名がないため、初めて実行するとき「Windows によって PC が保護されました」と出ることがあります。
「詳細情報」→「実行」で起動できます。zip を右クリックして「プロパティ」→「許可する」にしてから展開しても、出なくなります。
